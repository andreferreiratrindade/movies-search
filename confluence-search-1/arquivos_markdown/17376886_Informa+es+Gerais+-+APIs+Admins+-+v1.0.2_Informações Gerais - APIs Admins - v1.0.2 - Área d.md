                            # Informações Gerais - APIs Admins - v1.0.2 - Área do Desenvolvedor - Open Finance Brasil - Área do Desenvolvedor

                            As APIs administrativas são recursos que podem ser consumidos apenas pelo Diretório para avaliação e controle da qualidade dos serviços fornecidos pelas instituições financeiras.
Métricas
: (GET /admin/v1/metrics)
Visão geral
Este
endpoint
possibilita ao Diretório consultar estatísticas operacionais das APIs disponibilizadas pelas instituições financeiras, a fim de avaliar a qualidade dos serviços fornecidos ao usuário final.
