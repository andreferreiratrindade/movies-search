                            # Change log (Segurança) - Área do Desenvolvedor - Open Finance Brasil - Área do Desenvolvedor

                            No Portal do Desenvolvedor, foi criado uma página (Histórico de Segurança), que contém o Change Log, com todas as informações sobre as alterações e histórico das versões anteriores.
O Change log, foi criado com os seguintes requisitos que precisam ser preenchidos, para garantir a rastreabilidade de todos as alterações.
De/Para - Versão
: Informar para qual versão a alteração esta sendo realizado.
Ítem de Trabalho
: Informar qual a proposta que foi realizada a discussão e aprovação da mudança.
Demandante
: Quem solicitou a mudança.
O que foi alterado?
: Informar todas as alterações do documento.
Motivador
: Informar qual o motivador da alteração.
